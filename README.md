### 🚀 Sobre Mim

Olá! Sou estudante de **Análise e Desenvolvimento de Sistemas** na Estácio e desenvolvedor focado na criação de soluções robustas de software. Tenho experiência prática no ciclo completo de desenvolvimento (Full Stack), desde a modelagem de bancos de dados até a construção de interfaces intuitivas e funcionais.

💡 **O que venho desenvolvendo:**
* **Aplicações Desktop e Web com Python:** Criação de ferramentas customizadas, integração de sistemas e interfaces gráficas modernas.
* **Sistemas de Gestão:** Desenvolvimento ponta a ponta de softwares internos voltados para a automação de processos, controle financeiro e gerenciamento de dados de usuários.
* **Soluções Web Dinâmicas:** Construção de páginas responsivas e otimizadas utilizando ecossistemas modernos de desenvolvimento front-end.

Tenho forte interesse em arquitetura de código, qualidade de software (QA) e otimização de performance. Sou focado na resolução de problemas operacionais através da tecnologia, sempre aplicando boas práticas de versionamento, documentação e organização de código.
